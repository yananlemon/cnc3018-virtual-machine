# v0.3：台面工作范围左上角为 XY0

这是用户选择的仿真坐标配置，不宣称是 LUNYEE 出厂固件的坐标或回零设置。机型尺寸仍采用当前产品页 Z80 标称配置，旧手册 Z78 的差异见 `lunyee-model.md`。

## 零点、方向和两种坐标

从机器正面看向台面，或点击正交“俯视”：机器 X 向右增大，机器 Y 向前增大（俯视画面向下），机器 Z 向上抬刀增大。正常运动范围为 X[0,300]、Y[0,180]、Z[-80,0]mm。俯视快捷视角使用正交投影、屏幕上方对应台面后方；三维网格绘制 0,0、X/Y 箭头和有效工作范围边框。

XY0 是 **300×180mm 有效工作范围的左后角**。照片估计的台面为 320×200mm，两侧留 10mm 边缘；零点不是超出行程的金属板外沿。中央示例木板是较小的工件，不占满全行程。木板上的加工零点可用 G92 单独设置。

GUI 明确显示机器 `MPos` 和工件 `WPos`，`WPos=MPos-WCO`。Home 建立机器基准；G92 只改 WCO/工件坐标，不移动模型、不重新定义机器行程。Home 保留已有 G92，所以有工件偏置时机器 XY0 处的 WPos 可以不为零。Reset 清除 G92，并使机器基准失效，但保留实际位置。解锁也不会移动或建立基准。

## Home：触发、定位、退让和重新定基准

使用预设健康限位开关，运动仍由内核积分执行，并驱动同一套三维变换。没有把原来的负坐标只加常数显示在 DRO 上。

| 阶段 | 实际目标与行为 | 基准 |
|---|---|---|
| 0 | Z 快速向上找到开关，Z=0 | 未定位 |
| 1 | Z 向下退让 2mm，Z=-2，释放开关 | 未定位 |
| 2 | Z 慢速再次到开关，Z=0 | 确立 Z 上端基准 |
| 3 | Z 最终退让到 -2，释放开关 | Z 已定位 |
| 4 | XY 快速向负方向找到开关，XY=(-2,-2) | XY 未定位 |
| 5 | XY 向正方向退让到 (0,0)，释放开关 | XY 未定位 |
| 6 | XY 慢速回到开关，将触点定为各轴 -2 | 确立 XY 基准，零点位于触点内侧 2mm |
| 7 | XY 实际向正方向退让 2mm，到 (0,0) | 所有开关释放，Home 完成 |

完成时 `MPos=(0,0,-2)`，`planned=MPos`，已回零为 true，且只在全部步骤结束后发一个 `ok`。回零寻找开关时 XY 可以短暂进入 -2…0；普通运动和 Jog 不允许使用这段开关空间。`$$` 中回零方向掩码为 `$23=3`，表示 XY 负向、Z 正向，本内核有自己的退让零点规则。

`homeSwitches` 快照显示接触状态；`referencedAxes` 在慢速定位时逐轴成立，Reset/报警使其失效。GUI 回零时显示阶段和开关状态。模型依旧假设健康开关，没有开关卡住、线路故障、超时、抖动或电机失步模拟；硬限位故障按钮仍是独立报警注入。

## Home 后为什么有些点动被拒绝

| 从 (0,0,-2) 发出命令 | 结果 |
|---|---|
| X+5 | 成功，到 X=5，刀具向右 |
| Y+5 | 成功，到 Y=5，刀具相对工件向前；实体台面向后移动 |
| X-5 / Y-5 | 超出 XY 下界，`error:15`，本次指令未接受、不丢失基准；已有点动队列仍可继续 |
| Z+5 | 目标 Z=3 超过上界，`error:15`；剩余抬刀空间只有 2mm |
| Z+2 | 允许到正常坐标上界 Z=0 |
| Z-5 | 成功降低到 Z=-7 |

进到 X=5/Y=5 后，相应 -5 可以返回零点。GUI 使用“左/右、后/前、降/抬”按钮和中文越界解释。普通 G-code 越界触发 `ALARM:2`；范围检查用加入工件偏置后的机器目标，不能用工作坐标绕过限位。圆弧还检查经过的极值。

## 三维映射和圆弧方向

世界坐标以 Y 向上、Z 朝机器前方：

```text
刀尖世界 = (MX - 150, MZ + 154, 0)
台面世界 Z = 90 - MY
刀尖/轨迹的台面局部 = (MX - 150, MZ + 154, MY - 90)
```

XY0 对应局部左后角 (-150,-90)。Y 增大时台面后退，而刀具相对工件向前；工件与历史轨迹跟随台面。这改变了控制器行程、目标规划和真实父子变换，不只是改读数。

**G2/G3 保留原来的数值角度语义**：G17 的数值 XY 平面使用 `atan2(Y,X)`，G2 负角、G3 正角，I/J 仍是相对起点的圆心偏移，未交换 G2 与 G3。由于选择了俯视 Y 向下，数值 XY 到画面的映射发生镜像，因此本配置中 **G2 在俯视画面显示逆时针、G3 显示顺时针**。界面明确显示这点，不能用屏幕视觉方向误判数值圆弧。该用户配置不应冒充惯常右手 CNC 坐标系或厂商默认设置。

例如起点 MXY=(160,90)，圆心=(150,90)：`G2 X150 Y80 I-10 J0` 经过数值 Y<90，俯视向上；`G3 X150 Y100 I-10 J0` 经过数值 Y>90，俯视向下。测试覆盖中间点、终点及台面局部映射。整圆和 Z 螺旋插补规则不变。

示例改为先用 G53 G0 到 MPos=(120,65,-65)，`G92 X0 Y0 Z5` 建立示例工件偏置；木板表面仍是机器 Z=-70，浅切 WZ=-1/-2，结束 WZ=5。v0.1/v0.2 的负 X/Y 绝对坐标程序需要转换后才能用于 v0.3；旧 EXE、源码快照和 ZIP 保留供对比。

## 实际验收

8 组 CTest 包括原有协议、工作坐标/圆弧、发送器、数值保护、串口生命周期、网格，以及新增原点契约：8 个回零阶段、开关触发/释放、慢速建立基准、最终停车、正负 Jog、上下限、G92/Home 分工、镜像圆弧。

GUI 自检保存真实 Home 时的 `home-gui.png`、`home-top.png`，点动到 (5,5,-7) 的 `jog-positive-gui.png`，完整示例结束的 `gui.png` 和多视角。`smoke.json` 包含 8 阶段实际位置/开关/基准、9 条点动检查、6 段点动完成，以及程序单独的 17 行发送/确认、12 段运动完成。Z 极限图片仍为检查用显示快照，不冒充运动执行。

独立便携包解压启动测试采用仅 Windows 系统目录的 PATH。外部 sender 与虚拟 COM 端口对尚未联机验证；应用不创建虚拟端口。逐段零速出入、健康开关回零、自定义 GRBL 子集等已有边界仍适用。

新增完整示例验收：使用同一发送器依次运行已有非零G92下的首次示例、直接重复示例、Home保留G92后的再次示例，三次各17行全部确认、12段完成、终点MPos=(135,90,-65)。示例的定位段采用G53，随后G92建立自己的工件偏置，避免重复运行时叠加工件坐标。GUI自检Home/Jog复用与相应按钮完全相同的sendLine路径；回零阶段文本保持四行，不增加窗口最小高度。
