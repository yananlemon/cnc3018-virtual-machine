# v0.4 真正的雕刻仿真

材料去除由控制器实际执行的 MotionStep 驱动，包含起点、终点、运动类型与执行时主轴状态。已发送和已确认的命令不会提前切削木板。G1/G2/G3 且主轴转速大于零才去除木料；G0、Jog、Home、主轴关闭时只记录接触诊断。

## 操作

连接 → Home → 载入 G-code → 核对加工设置 → 运行 → 工件特写。新任务根据刀路包络居中布置木板，以木板表面为工作Z0。文件Tool/JOB等注释仅提供刀具和厚度候选；未识别刀具时默认3.175mm平刀，必须核对。包含G53/G92或相对坐标的程序使用手动设置，避免自动改写其坐标语义。

“准备表面零点”利用当前机器位置设置G92偏置，定义程序X0/Y0及木板表面Z0，不移动机器或木板。自动导入的刀尖高度基准148mm是一种模拟装夹设置，台面高度70mm、Z行程-80…0，最低刀尖68mm；并非实机标定值。内置示例仍采用原来的154mm基准。

加载新的“载入 G-code”任务会建立新毛坯。“接续加工”保留木板、去除形状和零点，只更换刀具候选，适用于同一坐标系的粗/精加工文件。加工设置中仅改刀具同样保留木板；改尺寸、位置、网格或高度基准会建立新毛坯。Reset清空控制器及G92，但保留木板；再次Home后可重新准备零点。手动工件零点具有用户优先权。

## 几何与画面

木板采用2.5D高度场，每个采样保存剩余木料高度。平刀为圆形平底，球刀为球面，V刀包含夹角和刀尖平面。直线段对整个扫掠求最低包络，包含坡度和垂直下刀，不是以离散圆点盖章。只合并同向共线直线；圆弧沿控制器2ms实际插补运动处理。GUI刷新频率和仿真倍率不改变直线扫掠结果。

默认请求0.1mm间距，最多200万个高度采样，超过容量时自动提高有效间距。设置界面允许0.025…2mm；界面显示调整后的实际间距。细节精度同时受G-code本身采样、刀具参数和网格限制。大件不会悄悄截断刀路。

显示使用分块索引三角网格、实际表面法线、底面/外侧壁；局部切削更新受影响网格。木纹为程序生成的近似材质，切削轮廓与深度来自几何；槽内阴影读取实际剩余高度，采用有限距离近似。四倍抗锯齿、透视和正交俯视可用。成品查看默认不透明、刀路隐藏。工件特写隐藏机器以便检查雕刻，鼠标可继续旋转缩放。

STL导出当前表面、底面与外侧壁，Y向上，单位mm，含装夹位置；支持中文路径。几何测试覆盖跨块闭合与穿透开口，每条焊接几何边有两条反向面边。STL没有木纹/颜色。

## 验证

验证使用实际加工文件完整执行，不修改原始文件。测试输入与含本地路径的详细记录不包含在源码仓库中。覆盖平刀粗加工、3.175mm球刀浮雕、6.35mm/60°V刀精加工、7.6MB球刀文件，以及平刀粗加工后接续V刀精加工。验证包含确认数=总命令数、错误为零、最终Idle、去除体积、最大深度、实际网格、接触计数、OpenGL画面和重复加工幂等性。

自动测试覆盖平/球/V解析截面、倾斜扫掠与不同分段/刷新的一致性、G0/主轴关闭不切削、暂停/恢复、Reset/G92保留木料、换刀保留材料、圆弧实际执行切削、跨块/穿透网格闭合，及中文注释/单位/刀具候选/不支持指令的导入处理。

## 当前范围

这是几何雕刻与机器运动仿真。高度场适用于三轴木板雕刻、开槽、型腔和浮雕，不支持倒扣、侧铣多层腔体或旋转轴。接触统计为扫掠段计数，不能当作独立事故次数；只涉及刀尖/刃长与木料、木板底面，未实现完整刀柄、夹具和机器之间的碰撞求解。接触诊断不会自动中断仿真。没有木纤维、毛刺、断刀、切削力、温升或实机尺寸误差模型。

控制器仍逐段停稳，没有GRBL前瞻，因此模拟时长不代表实机加工时间。外部虚拟COM sender未联机验证。本程序不会驱动或启动真实CNC机器。

同一球刀小件以0.1mm及0.05mm网格完整执行，去除体积分别21325.253和21379.579mm³，相差约0.254%；这是网格收敛对比，不能作为与实物加工误差的上界。
