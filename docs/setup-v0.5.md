# v0.5 自定义木板、夹具和右键平移

入口：“木板 / 夹具 / 刀具”。窗口分为木板和零点、夹具、刀具三个页签。

木板设置：宽X、深Y、厚度、左上角在台面的X/Y、程序原点在台面的X/Y、刀尖高度基准、网格间距。台面坐标左上为0,0，X向右/Y向前。程序XY0可选自定义、木板左上角或木板中心；Z0仍在木板上表面。“木板放到台面中央”按当前宽深计算摆放位置。

“保留我的木板设置”默认在手动设置窗口勾选。应用后导入新G-code保留木板尺寸、位置和原点，建立新毛坯；接续加工保留雕刻表面。取消该选项则使用文件刀路包络生成建议木板。G53/G92等自带机器坐标程序仍保留其坐标语义。

夹具设置：最多四个槽位，可全部关闭。“根据木板自动布置两只夹具”开启时跟随木板摆放；关闭后可独立编辑。X/Y指夹具螺杆的台面位置；朝向0°指向X+、90°指向Y+、180°指向X-、270°指向Y-。长度是压板长度，宽度为横向宽度。勾选“随板厚”时压板底面自动位于木板原始上表面；取消后可设置其距台面的高度。夹具与台面一起进行Y运动。夹具编辑保留当前木料和工件坐标，当前未加入夹具完整碰撞求解。

刀具页可设置平/球/V刀及尺寸，并选择导入时是否使用文件中的已识别刀具参数。自定义木板模式下，文件没有可识别刀具时保留当前刀具。

应用设置保存到exe同目录setup.json，启动时读取；保存此装夹可将窗口当前参数另存JSON，无需先应用；载入装夹会建立新毛坯。配置数值在应用前验证，尺寸越出工作范围或夹具参数无效时不应用。配置只包含结构化数值和开关。

视角：左键旋转、右键平移、滚轮缩放。平移沿当前相机的屏幕右/上方向，距离随观看距离和窗口高度换算；正交俯视采用对应投影跨度。机器实际坐标、装夹、木料和G92不会改变。复位视角清除平移。切换工件特写或预设视角会重新居中；工件特写的预设观看距离按工件尺寸计算，避免切换视角时突然变小。

验证：11项CTest通过。GUI实际鼠标事件覆盖普通透视、旋转并缩放的透视、正交俯视；右键拖动120×50像素，三个画面内参考点均对应移动120×50像素，机器位置和木料不变。验证自定义180×100×18mm木板在导入后保持参数、四只自定义夹具、仅修改夹具后保留雕刻和WCO、JSON保存/恢复、各设置页截图。
