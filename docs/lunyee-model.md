# LUNYEE 3018 Pro Ultra — v0.3 机型重建与验收

2026-10-08。本项目依据指定型号的官方照片和装配资料重建，使用 C++ / Qt / OpenGL 三角网格与机械父子变换。没有使用制造商 CAD，也不声称是可用于制造、干涉校核或实机设置的尺寸模型。v0.1/v0.2 的便携目录和 ZIP 保留。坐标配置已更新为左上XY0，详见 [v0.3坐标说明](coordinates-v0.3.md)。

## 结构与运动

- 4040 底架、薄金色前后端板、薄金色两侧立板、两条 2040 X 横梁、HGH15 外观与滑块，取代 v0.1 通用块状机架。型材槽为凹截面几何。
- 右侧 X 电机、左侧 X 手轮；前侧 Y 手轮、后侧 Y 电机；顶部 Z 电机及手轮。黑色 NEMA 外壳、端盖、叠片、紧固件和联轴器为独立网格。
- Z 背板在导杆后方，双圆杆与中心丝杆从正面可见。金色夹座有真实 Ø52 通孔，主轴筒身、冷却罩、轴颈、ER11 外观和刀具随 Z 滑座移动。
- 固定 Z 端板前沿 z=-29，主轴后缘 z=-26，保留 3mm 模型间距；Z0 / Z-80 检查截图核对该让位关系。此局部几何核对不能替代全机碰撞检测。
- 台面孔为开放网格，10mm 网格/5mm 尺边刻线采用单面几何、主线加粗、polygon offset；透视近面 10mm 避免深度冲突。压板内侧接触木板顶面，螺柱位于工件外侧。
- 六个可见微动限位、右侧红色急停、后方电控板和并排电源箱、安装支架及线缆。没有附加刀仓、探头或激光模块。三维急停是外观零件，操作使用 GUI 暂停/Reset。

X 只平移 X/Z 组件；Y 只平移台面、工件和历史切削轨迹；Z 只平移夹座、主轴和刀具。世界 Y 向上：刀尖 `(MX-150, MZ+154, 0)`，台面世界 Z=`90-MY`，轨迹存于台面局部 `(MX-150, MZ+154, MY-90)`。显示读取控制器实际执行快照，不由发送/确认计数移动。

木板表面 MZ=-70；示例先到 -65，再 `G92 Z5`，浅切工作 Z=-1/-2，抬刀到 Z5。绿色线仅显示主轴开启且接触工件的实际执行轨迹；没有材料去除。Z 最低 -80 对应刀尖高 74，距台面 4mm。

## v0.3 验收与边界

Release 编译启用警告视为错误；8 组 CTest 通过，包括原协议/坐标/发送器/数值/串口生命周期，以及机械网格有限数值、单位法线、非退化三角形、真实孔洞、孔单元面积、夹座通孔和圆角轮廓端点处理。Z80 上下端可执行，越界触发软限位。

截图目录 `verification` 包含真实 Home GUI/俯视、点动到(5,5,-7)的GUI、完整程序结束 GUI、正面、左前、背面、俯视、Z 最低/最高。Z 极限图片仅设置检查用显示快照，不改变内核运动位置或冒充执行记录。`smoke.json` 记录真实程序结果：17 行全部发送并确认、12 段运动完成、Idle、RX/队列为空、无发送错误、已回零和 OpenGL 可用。

便携包解压后用仅 Windows 系统目录的 PATH 启动，并执行相同自检。该测试在本机 Intel UHD Graphics 730 完成，不代表第二台干净 Windows 机器或所有显卡驱动验证。

外部 sender / 虚拟 COM 端口对未验证：本机只发现 COM1，应用打开已有端点，不创建虚拟串口。控制协议仍为自定义 GRBL 1.1 子集，逐段零速出入、健康限位回零，不是厂商 GRBL 1.1f 固件或 grblHAL 等价实现。所有 v0.1 协议边界仍适用，详见 README。
